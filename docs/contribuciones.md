# Contribuciones al proyecto LexCore

## Trabajo colaborativo

El desarrollo de LexCore se realiza mediante un flujo de trabajo colaborativo utilizando Git y GitHub.

Cada integrante del equipo trabaja en una rama `feature` independiente, permitiendo desarrollar y documentar cambios sin afectar directamente las ramas principales del proyecto.

## Proceso de contribución

Para realizar una contribución se sigue el siguiente proceso:

1. Trabajar en la rama personal correspondiente.
2. Realizar cambios pequeños y verificables.
3. Revisar los archivos modificados con `git status`.
4. Registrar los cambios mediante commits descriptivos.
5. Enviar los commits al repositorio remoto mediante `git push`.
6. Integrar posteriormente los cambios con la rama de desarrollo.

## Buenas prácticas

- Evitar trabajar directamente sobre `main`.
- Utilizar mensajes claros y descriptivos en los commits.
- Revisar los cambios antes de realizar un commit.
- Mantener actualizada la documentación.
- Evitar modificar archivos que estén siendo trabajados por otro integrante.
